# Glosario

| Término | Significado |
|---|---|
| **Microcápsula** | Unidad corta de material de estudio, al estilo de una lección de Duolingo. |
| **Trayecto** | ⚠️ **En desuso desde 2026-11-12.** Reemplazado por la versión 2 (ver abajo); esta definición pasó a ser la de **Bloque**. Motivo: el usuario aclaró que un trayecto es un conjunto de cursos. Definición anterior: Secuencia de microcápsulas que el alumno recorre. Al terminarlo responde una autoevaluación. |
| **Trayecto** (versión 2, vigente desde 2026-11-12) | Conjunto de cursos que el estudiante completa. Un trayecto se compone de cursos. |
| **Bloque** | Unidad didáctica: agrupación temática de varios temas y microcápsulas, como las unidades de un libro. Es la forma principal de organizar el material. Una clase puede desarrollar uno o varios bloques; eso depende de cada curso. Es lo que antes se llamaba "trayecto": una secuencia de microcápsulas que el alumno recorre y que, al terminarla, cierra con una autoevaluación. |
| **Práctica** | Tipo de material: actividades para aplicar la teoría de un bloque. |
| **Resumen** | Tipo de material: pantallazo que sintetiza lo aprendido en el bloque y prepara para el examen multiple choice. |
| **Curso** | Conjunto de clases y material que dicta un profesor, en fechas y una sede definidas. |
| **Clase** | Encuentro de un curso que aparece en el calendario, con su tema. Ahí se registra la asistencia con QR. |
| **Sede** | Lugar de la organización al que se asocian alumnos y cursos. |
| **Correlativa** | Curso que hay que tener aprobado para poder inscribirse a otro. |
| **Acreditación de competencias** | Forma de reemplazar una correlativa: examen multiple choice, evidencias o proyecto. |
| **Autoevaluación** | ⚠️ **En desuso desde 2026-11-12.** Reemplazado por la versión 2 (ver abajo). Motivo: lo que se llamaba trayecto ahora es bloque. Definición anterior: Multiple choice al final de un trayecto que mide cuánto comprendió el alumno. No es asistencia. |
| **Autoevaluación** (versión 2, vigente desde 2026-11-12) | Multiple choice al final de un bloque que mide cuánto comprendió el alumno. No es asistencia. |
| **Limes** | Moneda de Acadelime (reemplaza al XP). El alumno la gana al completar nodos de los bloques y la canjea en la tienda. Es global para todos sus cursos y no afecta notas. |
| **Tienda** | Catálogo de material extra para cualquier curso (skills para IA, videos con material adicional) que el alumno canjea con limes. |
| **Trayectoria académica** | Historial completo del alumno: cursos, estados, notas, asistencias, autoevaluaciones, acreditaciones y certificados. |
